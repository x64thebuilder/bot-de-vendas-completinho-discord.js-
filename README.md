# Bot Discord

creator: x64thebuilder/.200021

## Setup

1. Copie `.env.example` para `.env` e preencha:
   - `DISCORD_TOKEN`
   - `DISCORD_CLIENT_ID`
   - `OWNER_ID`
   - `GUILD_ID`
2. `npm install`
3. `npm run deploy`
4. `npm start`

## Estrutura

- `src/` — codigo do bot
- `data/` — database local (vazia por padrao, preenchida em runtime)
- `assets/` — imagens/fontes
- `Emojis/` — emojis sincronizados com a aplicacao
- `scripts/` — utilitarios
