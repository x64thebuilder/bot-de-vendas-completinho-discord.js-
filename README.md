# Bot Completo de Vendas

Um bot completo para **vendas e gerenciamento de servidores no Discord**, reunindo sistemas de vendas, tickets, pagamentos, middleman, Robux, sorteios e muito mais.

> **Criador:** `x64thebuilder / .200021`

---

## Sobre o projeto

Este projeto foi desenvolvido para oferecer uma solução completa e personalizável para servidores que trabalham com vendas.

O código pode ser **editado, modificado e adaptado livremente** para atender às necessidades do seu projeto.

---

## Instalação

### 1. Configure o ambiente

Preencha corretamente as informações necessárias no arquivo `.env`.

### 2. Instale as dependências

```bash
npm install
```

### 3. Inicie o bot

```bash
npm start
```

---

## Funcionalidades

- Sistema de Vendas
- Sistema de Tickets
- Sistema de Middleman
- Sistema de Robux
- Sistema de Sorteios
- Pagamentos manuais
- Pagamentos automáticos
- Diversas opções de configuração e gerenciamento

---

## Formas de pagamento

O bot possui suporte para:

- `Pix`
- `Mercado Pago`
- `Efí Bank`
- `Stripe`
